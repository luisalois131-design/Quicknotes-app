
# QuickNotes

QuickNotes is a simple, responsive note-taking web application built with HTML, CSS, and JavaScript. It allows users to create and organize notes into Personal, Work, and Study categories, search through saved notes, delete individual notes, and retain their notes using browser local storage.

## Features

- Add notes with Personal, Work, and Study categories.
- Validate empty notes and notes exceeding 200 characters.
- Display notes with their category and creation date.
- Delete individual notes.
- Search notes using case-insensitive text matching.
- Display an informative message when no search results match.
- Show the correct count of saved notes.
- Save notes to local storage so they survive page refreshes.
- Responsive layout for desktop and mobile screens.

## Technologies Used

- HTML5 for page structure and semantic elements.
- CSS3 for styling, Flexbox, category colours, and responsive design.
- JavaScript for note management, validation, search, and rendering.
- Browser localStorage for data persistence.
- Git and GitHub for version control and project hosting.

## How to Run Locally

1. Clone this repository:

   ```bash
   git clone https://github.com/luisalois131-design/Quicknotes-notes.git
   ```

2. Navigate into the project directory:

   ```bash
   cd quicknotes-app
   ```

3. Open `index.html` in your web browser.

   Alternatively, open the folder in Visual Studio Code and run
   `index.html` using the Live Server extension.

No package installation or build process is required.
